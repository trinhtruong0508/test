## Color Scheme (Default)

- **Primary Color**: Blue (#007bff) - Links, primary buttons
- **Success Color**: Green (#28a745) - CTA buttons, checkmarks
- **Danger Color**: Red (#dc3545) - Sale badges, urgent elements
- **Purple Gradient**: (#667eea to #764ba2) - CTA section background
- **Text Colors**: 
  - Primary: #333 (dark gray)
  - Secondary: #666 (medium gray)
  - Muted: #999 (light gray)

## Typography Hierarchy

```
H1 (Headline)        : 2.5rem (40px) - Bold
H2 (Section Title)   : 2.0rem (32px) - Bold
H3 (Subsection)      : 1.5rem (24px) - Semi-bold
Body Text            : 1.125rem (18px) - Regular
Small Text           : 0.875rem (14px) - Regular
```

## Spacing System

- Extra Small: 0.5rem (8px)
- Small: 1rem (16px)
- Medium: 2rem (32px)
- Large: 3rem (48px)
- Extra Large: 4rem (64px)

## Responsive Breakpoints

- Mobile: 0 - 768px
- Tablet: 769px - 1024px
- Desktop: 1025px+

## Component Behavior

### On Mobile (≤768px):
- Single column layout
- Stacked product cards
- Full-width images
- Reduced font sizes
- Condensed spacing

### On Desktop (≥1025px):
- Multi-column grid for products (2-3 columns)
- Side-by-side layouts
- Larger images
- Full typography scale
- Generous spacing

## Accessibility Features

- ✓ Semantic HTML structure
- ✓ ARIA labels where needed
- ✓ Keyboard navigation support
- ✓ Focus indicators
- ✓ Color contrast compliance
- ✓ Alt text for images
- ✓ Screen reader friendly

## Performance Optimizations

- ✓ Lazy loading for images
- ✓ Optimized CSS (no unused styles)
- ✓ Minimal JavaScript
- ✓ Mobile-first approach
- ✓ Fast page load times
