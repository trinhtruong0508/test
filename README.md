# Shopify Advertorial Page Template

A comprehensive, customizable advertorial page template for Shopify stores. This template is designed to create engaging editorial-style content that naturally integrates product promotions.

## Features

- 📝 **Editorial-Style Layout**: Professional content presentation that builds trust
- 🎨 **Fully Customizable**: All sections can be customized through Shopify's theme editor
- 📱 **Responsive Design**: Looks great on all devices (mobile, tablet, desktop)
- 🛍️ **Product Integration**: Seamlessly showcase products within editorial content
- ⚡ **Performance Optimized**: Fast loading with lazy-loaded images
- 🎯 **Conversion Focused**: Strategic CTAs and product placements
- ♿ **Accessible**: Built with web accessibility standards

## Installation

### Step 1: Upload Files to Your Shopify Theme

1. Go to your Shopify Admin → Online Store → Themes
2. Click "Actions" → "Edit code" on your current theme
3. Upload the files to their respective directories:
   - `templates/page.advertorial.liquid` → Templates folder
   - `templates/page.advertorial.json` → Templates folder
   - `sections/advertorial-header.liquid` → Sections folder
   - `sections/advertorial-main.liquid` → Sections folder
   - `sections/advertorial-products.liquid` → Sections folder
   - `sections/advertorial-cta.liquid` → Sections folder
   - `assets/advertorial.css` → Assets folder

### Step 2: Create a New Page

1. Go to Online Store → Pages
2. Click "Add page"
3. Enter your page title (e.g., "Product Review: Best Solution for...")
4. In the "Theme template" dropdown, select "page.advertorial"
5. Add your main content in the editor (optional, as sections handle most content)
6. Save the page

### Step 3: Customize Your Advertorial

1. Navigate to your newly created page
2. Click "Customize" to open the theme editor
3. You'll see the following sections:
   - **Advertorial Header**: Hero image, headline, author info
   - **Advertorial Main Content**: Add text, images, quotes, and lists
   - **Advertorial Products**: Feature products with descriptions
   - **Advertorial CTA**: Final call-to-action section

## Section Guide

### Advertorial Header Section

Configure the hero area:
- **Featured Image**: Upload a compelling hero image
- **Headline**: Main attention-grabbing title
- **Subheadline**: Supporting description
- **Author Info**: Name, image, and publish date for credibility

### Advertorial Main Content Section

Build your editorial content with multiple block types:

**Text Block**: Standard paragraphs with optional headings
**Image Block**: Visual content with captions
**Quote Block**: Customer testimonials or expert quotes
**List Block**: Bullet points for features or benefits
**Spacer Block**: Add vertical spacing between content

### Advertorial Products Section

Showcase products within your content:
- Select products from your catalog
- Add custom descriptions
- Display ratings and reviews
- Show sale badges
- Customize button text

### Advertorial CTA Section

Final conversion section with:
- Compelling headline and description
- Benefit list (up to 4 benefits)
- Prominent call-to-action button
- Trust badges and guarantees

## Best Practices

### Content Strategy

1. **Start with a Problem**: Address a pain point your audience faces
2. **Build Credibility**: Use author bios, research citations, testimonials
3. **Provide Value**: Offer genuine insights and helpful information
4. **Natural Product Integration**: Don't make it too salesy
5. **Strong CTA**: Clear next steps for the reader

### SEO Tips

- Write descriptive, keyword-rich headlines
- Use alt text for all images
- Structure content with proper headings (H1, H2, H3)
- Keep paragraphs concise and readable
- Include internal links to related products

### Conversion Optimization

- Place products strategically within content
- Use social proof (reviews, testimonials)
- Create urgency with limited-time offers
- Highlight guarantees and risk-free trials
- Make CTAs clear and prominent

## Troubleshooting

**Template not appearing?**
- Ensure all files are uploaded to correct directories
- Check file names match exactly (case-sensitive)
- Refresh your theme editor

**Sections not customizable?**
- Verify JSON schema is properly formatted
- Check for syntax errors in Liquid files
- Ensure you're using a Shopify 2.0 compatible theme

**Styling issues?**
- Verify advertorial.css is uploaded to Assets
- Check for conflicting styles in your theme
- Clear browser cache
